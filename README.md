# claude-team-relay

**팀원들의 Claude Code 세션끼리 실시간으로 대화하게 하는 채널.**

한 팀원이 자기 세션에 "○○에게 이거 물어봐"라고 말하면, 상대 팀원의 에이전트가 자기 로컬
작업 맥락(아직 커밋하지 않은 결정까지)을 근거로 자동 답장한다. 사람이 메신저로 옮겨 적을
필요 없이, 서로 다른 머신의 에이전트끼리 인터페이스를 맞춘다.

## 어떻게 동작하나

두 개의 Claude Code 공식 기능을 뼈대로 삼고, 자체 코드는 "머신 사이 파이프" 하나로 최소화했다.

```
[A 팀원 머신]                                  [B 팀원 머신]
게이트웨이 세션 ──┐  ①웹소켓          ┌── 게이트웨이 세션
  (채널 플러그인) │                    │      (채널 플러그인)
                  ▼                    ▼
              ┌───────────────────────────────┐
              │       중계 서버 (사내망 1대)     │
              │  방·명부·인증 · 실시간 배달 ·    │
              │  오프라인 큐 · 감사 로그          │
              └───────────────────────────────┘
```

- **머신 사이**: 자체 채널 플러그인(공식 [channels](https://code.claude.com/docs/en/channels)
  확장면) ↔ 사내 중계 서버. 대화가 회사 밖으로 나가지 않는다.
- **머신 안 위임**: Claude Code 2.1.224 네이티브 크로스 세션 메시징 — 게이트웨이 세션이
  질문을 같은 머신의 담당 작업 세션에 넘겨 답을 받아 온다.
- **격리**: 방(room) 단위. 같은 방이 없는 팀원은 서로 보이지도, 닿지도 않는다.
- **신뢰 경계**: 팀원 메시지는 사용자 승인을 대신하지 못하고, 설정 변경 요구는 거부된다.

이 저장소는 팀원이 설치하는 **플러그인**만 담는다. 중계 서버 핵심 로직은 비공개 저장소에
분리돼 있다.

## 기능

메시지를 나르는 것만으로는 팀이 굴러가지 않는다. "답이 안 오면 어떻게 아나", "자리를
비우면 메시지는 어디로 가나", "무엇이 합의된 것인가" — 실제로 걸리는 지점들을 채널
안에서 푼다.

| | 하는 일 |
|---|---|
| **스레드 · 무응답 알림** | 질문↔답이 스레드로 묶인다. 15분간 응답이 없으면 발신자에게 알려 준다(한도 초과·자리 비움 등). 상대가 바쁘면 에이전트가 "작업 중" 수신 확인을 먼저 보낸다 |
| **퇴근 / 출근** | 퇴근 중 도착한 메시지는 보관되고 **보관 기한이 멈춘다**(연휴에 증발하지 않음). 출근하면 한꺼번에 배달되며, 2건 이상이면 에이전트가 **부재중 브리핑**부터 한다 |
| **자가 진단** | `/team-relay:doctor` — 설정·게이트웨이 선언·연결·수신 자격·보관 큐를 ✓/✗ 와 **처방**으로 점검한다. "메시지가 안 와요"의 1차 대응 |
| **히스토리** | 자기 문답만 조회한다(제3자 대화는 열람 불가). 상대에게 다시 묻기 전에 에이전트가 먼저 확인한다 |
| **합의 대장** | 문답으로 정해진 인터페이스를 **양측 에이전트가 대조 확인해야** 확정된다. 확정분은 같은 방 전원이 열람 |
| **방장** | 방장이 자기 세션에서 그 방의 초대·추방·공지를 한다. 서버 관리자가 병목이 되지 않는다 |
| **신원 / 라벨 분리** | 신원은 토큰 하나(머신당·불변), **이름은 방마다 다를 수 있다**. 한 사람이 여러 방에 다른 이름으로 참여 |
| **세션별 방 담당** | A세션은 1번 방, B세션은 2번 방을 받는다. `--resume` 하면 담당이 복원되고, 세션을 새로 켜는 것만으로는 **다른 세션의 수신을 뺏지 않는다** |
| **규약 원격 배포** | 에이전트가 지킬 대화 규약을 **서버가 배포**한다(thin client). 규칙을 바꿔도 팀원은 아무것도 하지 않는다 |
| **운영** | 감사 로그(월별 분할·화자별 색상·실시간 tail) · 24시간 자동 백업(14개 보존) · 비파괴 토큰 재발급 · 와이어 버전 협상(구버전은 명시적 거부) |

프라이버시: 팀 메시지는 팀 서버에 기록된다(감사 목적). 본인 문답만 조회 가능하며,
자세한 고지는 [사용 가이드](docs/user-guide.md)에 있다.

## 상태

Claude Code 채널은 research preview 기능이라, 설치본은 기동 시 개발용 플래그가 필요하다
(사용 가이드의 alias 에 포함). 조직 관리자가 플러그인을 허용 목록에 등록하면 이 플래그는 없어진다.
