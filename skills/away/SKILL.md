---
name: away
description: 퇴근/출근 전환 — 퇴근하면 팀 메시지가 서버에 보관되고(기한 정지) 출근하면 한꺼번에 배달된다. 사용법 — /team-relay:away on|off
---

사용자가 `/team-relay:away <on|off>` 를 실행했다.

1. 인자가 `on` 이면 `team_away` 를 `{ mode: "on" }` 으로 호출한다(퇴근). 결과를 그대로
   보여주고, 퇴근 중에도 발신("○○에게 보내줘")은 된다고 알린다.
2. 인자가 `off` 면 `{ mode: "off" }` 로 호출한다(출근). 보관돼 있던 메시지가 곧 채널로
   배달된다 — **2건 이상이면 개별 반응 전에 부재중 브리핑**(누가·무엇을·긴급도)을
   사용자에게 먼저 보고한다.
3. 인자가 없거나 다른 값이면 사용법을 안내하고 멈춘다: `/team-relay:away on|off`
4. "연결돼 있지 않습니다" 가 나오면 `/team-relay:join` 안내 또는 서버 상태 확인을 권한다.
