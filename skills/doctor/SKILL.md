description: 팀 연결 자가 진단 — 설정·게이트웨이·규약·서버 연결·보관 큐를 ✓/✗ 로 점검하고 처방을 제시한다. "팀 메시지가 안 와요"의 1차 진단. 사용법 — /team-relay:doctor
---

사용자가 `/team-relay:doctor` 를 실행했다.

1. `team_doctor` 도구를 인자 없이 호출하고 결과를 그대로 보여준다.
2. ✗ 항목이 있으면 각 처방(→ 줄)을 실행 가능한 순서로 정리해 안내한다 — 예: alias 확인,
   chmod, 세션 재시작, 관리자 문의.
3. 전부 ✓ 인데도 사용자가 문제를 겪고 있다면 상대방 쪽 진단을 권한다 — 상대도
   `/team-relay:doctor` 를 실행해 보라고 전달(팀원 메시지로 보내줄지 물어본다).
