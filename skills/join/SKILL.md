---
name: join
description: 팀 중계 서버에 참가한다 (최초 1회 또는 추가 방 합류). 사용법 — /team:join <서버주소> <초대코드>
---

사용자가 `/team:join <서버주소> <초대코드>` 를 실행했다.

1. 인자에서 서버 주소(예: `10.0.1.23:8765`)와 초대코드(`TR-…`)를 읽는다. 둘 중 하나라도
   없으면 형식을 안내하고 멈춘다: `/team:join <서버주소> <초대코드>`
2. `team_join` 도구를 `address`, `code` 인자로 호출한다.
3. 성공하면 결과(내 이름·소속 방·온라인 팀원)를 그대로 보여주고, 앞으로는 세션을 켤 때
   자동 접속된다고 알린다.
4. 실패하면 도구가 준 이유를 그대로 전한다 — 만료된 코드면 관리자에게 새 코드를 요청하라고,
   연결 실패면 서버 주소와 사내망(VPN) 연결을 확인하라고 안내한다.
