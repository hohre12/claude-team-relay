---
name: server
description: 중계 서버 주소를 변경한다 (서버 이사 — 초대코드 불필요, 토큰 유지). 사용법 — /team:server <새서버주소>
---

사용자가 `/team:server <새서버주소>` 를 실행했다. 서버 이사(관리자가 명부 데이터를 새
머신으로 복사해 기동한 경우)에 쓰는 명령으로, 재참가가 아니라 **주소만 갱신**한다.

1. 인자에서 새 서버 주소를 읽는다. 없으면 형식을 안내하고 멈춘다: `/team:server <서버주소>`
2. `team_server` 도구를 `address` 인자로 호출한다.
3. 접속까지 성공하면 결과(온라인 팀원)를 보여준다. "저장했지만 지금은 연결 안 됨" 이면
   백그라운드 재시도가 걸려 있다고 안내한다 — 서버가 켜지면 자동 연결된다.
4. 초대코드를 요구하지 않는 것이 정상이다 — 기존 토큰이 이사한 명부에서 그대로 유효하다.
